# Changelog

## 1.0.1
- Fix for The Shack Pack: with No Lossy Cooking Stations and ValheimCommunityPatch both installed, an item that reached a busy fermenter was handed back twice. Now only VCP's "Refund Rejected Station Items" hands it back (the same goes for a full cooking station). New admin setting "One refund per rejected item" (on). Mixes with 1.0.0.

## 1.0.0
- First release: the blast furnace takes copper ore, tin ore, scrap iron and silver ore and smelts them 4× as fast as the regular furnace, for the same coal per ore. Admin settings for which ores, the speed, the coal and the capacity.
